# 🦉 Виктория - Telegram Bot для пар

Игра для двоих, которая помогает стать ближе через разговоры, тактильные игры и откровенность.

## 🚀 Быстрый старт

1. **/start** - Начать работу с ботом
2. **Создать комнату** - Получить код для подключения
3. **Присоединиться** - Ввести код от партнера
4. **Начать игру** - Получить первое задание

## 🎮 Функции

- ✅ Создание игровых комнат
- ✅ 3 колоды карт (45 уникальных заданий)
- ✅ Умные таймеры с прогрессивными уведомлениями
- ✅ Бросок кубика для заданий
- ✅ Возможность пропустить любое задание
- ✅ Поочерёдная смена ролей

## 🛠 Технологии

- Python 3.11
- Aiogram 3.0
- Docker
- Render.com (хостинг)
