# Виктория 🦉 - Telegram Bot для пар

Игра для двоих, которая помогает стать ближе через разговоры, тактильные игры и откровенность.

## Как запустить

1. Создайте бота через @BotFather
2. Задеплойте на Render.com
3. Настройте переменные окружения
4. Начните игру!

## Функции

- Создание комнат для игры вдвоём
- Три колоды карт (Белая, Жёлтая, Красная)
- Таймеры с умными уведомлениями
- Отправка фото между партнёрами
- Бросок кубика для заданий
- Возможность пропустить любое задание
